# 🤖 AI-Powered Question Paper Generator

## 📌 Project Overview

AI-Powered Question Paper Generator is an intelligent application that automatically generates question papers based on the subject, topics, difficulty level, and question requirements provided by the user.

The system uses Artificial Intelligence to create relevant and well-structured questions, reducing the time and effort required to prepare question papers manually.

## 🎯 Objectives

- Automatically generate question papers using AI.
- Save teachers' time and effort.
- Generate questions based on selected topics.
- Provide different difficulty levels.
- Create balanced and well-structured question papers.
- Make question-paper preparation simple and efficient.

## ✨ Features

### 📚 Subject & Topic Selection
Users can enter the subject and topics from which questions should be generated.

### 🤖 AI Question Generation
The system uses AI to generate relevant questions based on the given requirements.

### 📊 Difficulty Levels
Questions can be generated according to:
- Easy
- Medium
- Hard

### 📝 Question Types
The system can generate different types of questions such as:
- Multiple Choice Questions
- Short Answer Questions
- Long Answer Questions

### 📄 Question Paper Creation
The generated questions are arranged into a complete question paper.

### 💾 Export
The generated question paper can be saved or exported for later use.
